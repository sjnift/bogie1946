About

Credits Roll reads the CSV files in a Letterboxd data export. It is not made by or affiliated with Letterboxd.

With your own TMDB key, film details come from The Movie Database. This product uses the TMDB API but is not endorsed or certified by TMDB. Inside the Claude app, details come from Claude's knowledge of each film instead, so check anything surprising.

On a phone? Open the phone version. It uses the same import.
